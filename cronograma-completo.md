# Cronograma de Estudos - 4 Meses

## Objetivo

Construir uma formação equilibrada entre:

- Desenvolvimento Web, com foco em criação e venda de sites.
- Backend profissional com Java e Spring Boot.
- Inteligência Artificial aplicada ao desenvolvimento.
- Agentificação do ambiente de desenvolvimento.
- Docker, deploy, CI/CD e fundamentos de arquitetura.

### Distribuição aproximada

- **40%** Web / Full Stack
- **30%** Backend / Java
- **20%** IA / Agentificação
- **10%** DevOps / Arquitetura

### Carga horária

- Segunda a sexta: **~2h30/dia**
- Sábado: **~3h**
- Domingo: descanso
- Total: **~15,5h/semana**
- Total em 4 meses: **~250 horas**

---

# Prioridades

## 1. Next.js + TypeScript + CSS + JavaScript

Motivo: é diretamente monetizável para criação de sites.

## 2. Spring Boot + PostgreSQL + REST

Motivo: mantém uma base forte de backend e permite construir aplicações completas.

## 3. IA + Agents + Tool Calling + MCP

Motivo: cria uma especialização diferenciada em IA aplicada ao desenvolvimento.

## 4. GitHub + Docker + Linux + CI/CD + Deploy

Motivo: transforma seus projetos em um fluxo profissional de desenvolvimento, colaboração, automação e publicação.

## 5. GitHub + AWS + Arquitetura

Importante, mas deve vir depois das competências anteriores.

## 6. Kafka

Deixar para depois.

Para o objetivo atual de **venda de sites + full stack + IA aplicada ao desenvolvimento**, Kafka possui uma relação custo/benefício menor neste momento.

# Resultado esperado ao final dos 4 meses

Ao terminar o cronograma, o objetivo é conseguir demonstrar três competências principais:

1. **Construir aplicações e sites profissionais para clientes.**
2. **Construir e integrar backends profissionais usando Java/Spring Boot e PostgreSQL.**
3. **Integrar IA ao desenvolvimento por meio de ferramentas, agentes, RAG, MCP e automação.**

A prioridade não deve ser simplesmente concluir tópicos. Cada mês deve produzir algo funcional que possa evoluir para o portfólio.
