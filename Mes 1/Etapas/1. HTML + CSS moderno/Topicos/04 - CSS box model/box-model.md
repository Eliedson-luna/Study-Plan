# Box Model

## O que é?

O Box Model é um termo abordado quando falamos sobre design e layout no desenvolvimento web. Se trata de uma caixa invisível que abraça todo elemento HTML.

Ela é dividida em quatro partes, sendo elas o `conteudo`, `padding`, `border` e `margin`, que são utilizadas para manipular o estilo do componente e como o espaço interno e externo dele se comporta.

## Partes

### Conteudo

O conteudo do elemento se trata daquilo que colocamos dentro dele, pode ser um texto, uma imagem, outro elemento ou conjunto de elementos. 

### Padding

É a propriedade que cria uma área entre a borda e o conteúdo do elemento, você pode usa-lo para aumentar ou diminuir a distância da borda para o centro do elemento.

### Border

A borda é o que fica entre o padding e o margin. Quando precisa de uma borda estilizada ou remove-la use as propriedades desse componente.

### Margin

A margin é o espaço externo do elemento, com ela você define o espaçamento entre os elementos dispostos na tela.
