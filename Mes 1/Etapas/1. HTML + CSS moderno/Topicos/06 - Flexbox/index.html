Flexbox

Flexbox é o conjunto de recursos relacionados ao comportamento flex do CSS.

Um componente Flexbox possui dois elementos principais: o Flex Container e o Flex Item.

O elemento que recebe display: flex; é o Flex Container. Os elementos diretamente dentro dele se tornam Flex Items.
