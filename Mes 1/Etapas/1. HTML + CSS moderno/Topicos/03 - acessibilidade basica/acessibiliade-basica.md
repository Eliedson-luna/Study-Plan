# Acessibilidade

## Conceito

A acessibilidade em páginas web é um assunto muito amplo que visa proporcionar a melhor experiência para todos os usuários. Eu diria que, se fosse para resumir a acessibilidade, seria da seguinte forma: "A acessibilidade é pensar nas pessoas que vão usar o seu produto e se colocar no lugar delas." Uma vez que existem bilhões de pessoas no mundo, é impossível que todas tenham as mesmas condições, não é mesmo?

## O Código Semântico

Como visto no primeiro tópico, usar o HTML de forma semântica é de extrema importância, e é quando a acessibilidade entra em jogo que vemos isso. De acordo com a forma como se escreve uma página, podemos dizer ao navegador onde cada elemento está localizado. Mas para quê?

Simples: imagine que você perdeu a capacidade de enxergar. E agora? Como você faria para navegar na internet? Você provavelmente usaria um plugin ou uma funcionalidade que lesse a página web para você através do HTML, e é aí que a semântica entra em jogo. Essas ferramentas utilizam elementos HTML para se guiarem no código, melhorando a entrega do conteúdo ao usuário.

Além da possibilidade de orientação guiada por voz utilizando elementos HTML, o uso de elementos semânticos proporciona a capacidade de navegação pelo teclado, um recurso muito útil para pessoas que não dispõem de um mouse para clicar em um botão, estão ocupadas com alguma outra tarefa ou não tenham uma das mãos, permitindo que naveguem pelo site sem muita dor de cabeça.
