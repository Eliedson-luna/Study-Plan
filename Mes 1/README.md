# Mes 1

## Sobre o primeiro mês

O primeiro mês servirá como uma revisão e reforço dos fundamentos do desenvolvimento de software, aquele conhecimento que vemos quando começamos a estudar sobre o assunto.

---

## Execução

Conforme avanço nos estudos vou estar completando cada tópico do cronograma em pastas que terão o mesmo nome do respectivo tópico. 

Como se trata de uma revisão acredito que leve menos de um mês para abordar tudo.
